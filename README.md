# hashes.space community store

An Umbrel community app store with the hashes.space apps:

- **hashes.space**: the Find Mempool page
- **Bitcoin Explorer**, **Bitcoin BLAKE2b Explorer**, **Dogecoin Explorer**, **Monero Explorer**

In Umbrel: *App Store, ⋯, Community App Stores*, add `https://github.com/yudikorsou/blockexplorer`.
